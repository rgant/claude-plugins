# Code review

- Every sentence must change what the author does. Cut the rest.
- Never recap their work, the diff, or what CI already reports.
- State my own check only when it is evidence for an ask, or a fact the author
  cannot get.
- An approval can name one thing done well, in one sentence. Never a list.
- Rank findings by severity. Report every real one. Length comes from the count,
  never from prose per finding.
- These are senior peers. Give one preferred fix with the facts behind it, never
  an order and never a menu.
